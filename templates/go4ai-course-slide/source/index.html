ReAct Architecture: Reasoning & Acting

Thought (Suy Luận)
Agent phân tích mục tiêu và lập kế hoạch bước tiếp theo.

Action & Observation
Thực thi công cụ (API, DB, Search) và quan sát kết quả trả về.
agent_loop.py 
while not is_finished:
    # 1. Thought step
    thought = await llm.reason(history)
    
    # 2. Action execution
    action = thought.select_tool()
    obs = await tools.execute(action)
    
    # 3. Observation append
    history.append({thought, obs})
